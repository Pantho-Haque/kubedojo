<p class="lead">kind runs real Kubernetes nodes inside containers. Now let's use real (virtual) machines and <b>k3s</b>, a lightweight but fully certified Kubernetes that's great for home labs, edge devices and learning.</p>
<p>k3s comes with the essentials built in: the <b>Traefik</b> ingress controller, a LoadBalancer implementation, <b>local-path</b> storage and <b>metrics-server</b>. We'll use <b>Multipass</b> to create 3 Ubuntu VMs on your Mac.</p>
<p style="font-size:15px;color:var(--mut)">💡 Run every step in the <b>same terminal window</b>, because later steps reuse the <code>$CP_IP</code> and <code>$TOKEN</code> variables.</p>
<h2>1 · Three machines</h2>
<label class="task"><input type="checkbox" data-task="k-mp"><span>Install Multipass</span></label><div class="cmd"><pre tabindex="0">brew install --cask multipass</pre><button class="copy">Copy</button></div>
<label class="task"><input type="checkbox" data-task="k-vms"><span>Create 1 control-plane VM + 2 worker VMs</span></label><div class="cmd"><pre tabindex="0">multipass launch --name cp --cpus 2 --memory 2G --disk 10G
multipass launch --name w1 --cpus 2 --memory 2G --disk 10G
multipass launch --name w2 --cpus 2 --memory 2G --disk 10G</pre><button class="copy">Copy</button></div>
<h2>2 · Install the control plane</h2>
<label class="task"><input type="checkbox" data-task="k-server"><span>Install k3s on “cp”</span></label><div class="cmd"><pre tabindex="0">multipass exec cp -- bash -c "curl -sfL https://get.k3s.io | sh -"</pre><button class="copy">Copy</button></div>
<label class="task"><input type="checkbox" data-task="k-token"><span>Grab its IP and the join token (the password workers use to join)</span></label><div class="cmd"><pre tabindex="0">CP_IP=$(multipass info cp | awk '/IPv4/ {print $2}')
TOKEN=$(multipass exec cp -- sudo cat /var/lib/rancher/k3s/server/node-token)
echo $CP_IP</pre><button class="copy">Copy</button></div>
<h2>3 · Join the workers</h2>
<label class="task"><input type="checkbox" data-task="k-join"><span>Install the k3s agent on w1 and w2 and point it at the control plane</span></label><div class="cmd"><pre tabindex="0">for w in w1 w2; do
  multipass exec $w -- bash -c "curl -sfL https://get.k3s.io | K3S_URL=https://$CP_IP:6443 K3S_TOKEN=$TOKEN sh -"
done</pre><button class="copy">Copy</button></div>
<h2>4 · Control it from your Mac</h2>
<label class="task"><input type="checkbox" data-task="k-kubeconfig"><span>Copy the kubeconfig (your “key” to the cluster) and use it</span></label><div class="cmd"><pre tabindex="0">mkdir -p ~/.kube
multipass exec cp -- sudo cat /etc/rancher/k3s/k3s.yaml | sed "s/127.0.0.1/$CP_IP/" &gt; ~/.kube/k3s.yaml
export KUBECONFIG=~/.kube/k3s.yaml
kubectl get nodes          # cp, w1, w2: all Ready 🎉</pre><button class="copy">Copy</button></div>
<p style="font-size:15px">A <b>kubeconfig</b> file tells kubectl which cluster to talk to and who you are. If you have several clusters, switch between them with <code>kubectl config get-contexts</code> / <code>kubectl config use-context &lt;name&gt;</code>.</p>
<h2>5 · Deploy with a real Ingress</h2>
<label class="task"><input type="checkbox" data-task="k-app"><span>Deploy pizza and route http://pizza.local to it through Traefik</span></label><div class="cmd"><pre tabindex="0">kubectl create deployment pizza --image=nginx:1.27 --replicas=3
kubectl expose deployment pizza --port=80
kubectl create ingress pizza --rule="pizza.local/*=pizza:80"
echo "$CP_IP pizza.local" | sudo tee -a /etc/hosts</pre><button class="copy">Copy</button></div>
<label class="task"><input type="checkbox" data-task="k-open"><span>Open http://pizza.local in your browser, then check which machine each pod is on</span></label><div class="cmd"><pre tabindex="0">kubectl get pods -o wide</pre><button class="copy">Copy</button></div>
<label class="task"><input type="checkbox" data-task="k-fail"><span>Real failure test: stop a worker VM, watch the node go NotReady, and see its pods replaced after a few minutes</span></label><div class="cmd"><pre tabindex="0">multipass stop w1
kubectl get nodes -w       # press Ctrl+C before the next command
multipass start w1</pre><button class="copy">Copy</button></div>
<h2>Where to go from here</h2>
<ul><li><b>Highly available control plane:</b> 3 server nodes with embedded etcd (<code>--cluster-init</code> in k3s), so losing one doesn't take down the brain.</li>
<li><b>kubeadm:</b> the official, more manual way to build a cluster. Do it once to see every moving part.</li>
<li><b>Managed Kubernetes</b> (EKS, GKE, AKS): for serious production, the cloud runs the control plane for you.</li></ul>
